## En quelques mots  
Allumer un ordinateur, c’est un peu comme allumer la télé : vous appuyez sur un bouton, l’écran s’allume et l’appareil se met en marche. Éteindre ou redémarrer, c’est comme éteindre la lumière ou rebrancher un appareil qui aurait besoin d’un petit « reset ». Vous ne risquez rien, votre machine ne « se casse » pas, elle suit simplement les instructions que vous lui donnez.

## Ce que vous allez apprendre  
- **Allumer** votre ordinateur en toute confiance.  
- **Éteindre** correctement pour éviter les pertes de données.  
- **Redémarrer** lorsqu’on vous le conseille (mise à jour, installation).  
- Différence entre les boutons **physiques** et les **menus** à l’écran.  
- Comment reconnaître que l’ordinateur est bien **hors tension**.

## Pas à pas  

### 1. Allumer l’ordinateur  

| Windows | Mac |
|---------|-----|
| 1. Repérez le **bouton d’alimentation** sur la tour (ou le côté du portable). Il ressemble souvent à un petit cercle ou à un symbole « ⏻ ». | 1. Sur un Mac, le bouton se trouve sur le côté droit du clavier (ou sur le boîtier si c’est un iMac). |
| 2. **Cliquez** doucement avec le **bouton gauche** de la souris ou **appuyez** avec votre doigt sur le bouton. | 2. **Appuyez** avec votre doigt sur le bouton d’alimentation. |
| 3. Attendez que l’écran s’allume ; vous verrez le logo Windows puis le bureau. | 3. L’écran affichera le logo Apple puis le bureau macOS. |
| 4. Si rien ne se passe, vérifiez que le câble d’alimentation est bien branché à la prise murale. | 4. Vérifiez le câble d’alimentation et la prise murale si l’écran reste noir. |

### 2. Éteindre correctement  

#### Sous Windows  

1. **Déplacez** le curseur (la petite flèche) vers le coin inférieur gauche de l’écran.  
2. **Cliquez** avec le **bouton gauche** de la souris sur le **menu Démarrer** (icône Windows).  
3. **Cliquez** sur le **bouton d’alimentation** qui apparaît (icône cercle avec une petite ligne).  
4. **Cliquez** sur **« Arrêter »**.  
5. Attendez que l’écran devienne complètement noir ; vous pouvez alors débrancher si besoin.

#### Sous macOS  

1. **Cliquez** avec le **bouton gauche** de la souris sur le **menu Pomme** () en haut à gauche.  
2. **Cliquez** sur **« Éteindre… »**.  
3. Une petite fenêtre apparaît ; **cliquez** sur **« Éteindre »** pour confirmer.  
4. L’écran s’éteint, le son du ventilateur s’arrête ; l’ordinateur est hors tension.

### 3. Redémarrer (reboot)  

> **Quand le redémarrer est recommandé** : après une mise à jour, lorsqu’un programme ne répond plus, ou quand on vous le demande pendant une assistance.

#### Windows  

1. Ouvrez le **menu Démarrer** comme indiqué précédemment.  
2. **Cliquez** sur le **bouton d’alimentation**.  
3. **Cliquez** sur **« Redémarrer »**.  
4. L’ordinateur s’éteint puis se rallume automatiquement.

#### macOS  

1. Cliquez sur le **menu Pomme** ().  
2. **Cliquez** sur **« Redémarrer… »**.  
3. Confirmez en **cliquant** sur **« Redémarrer »** dans la fenêtre qui s’ouvre.  

### 4. Vérifier que tout est bien arrêté  

- **Windows** : le ventilateur est silencieux, l’écran reste noir, aucun voyant lumineux n’est allumé.  
- **Mac** : le voyant d’alimentation (si présent) est éteint, l’écran reste noir.

## Les pièges à éviter  

1. **Débrancher le câble trop tôt** – Attendez toujours que l’écran soit noir et que le système indique qu’il est éteint.  
2. **Utiliser le bouton d’alimentation pendant que le système travaille** – Si le disque clignote, laissez le processus se terminer avant d’éteindre.  
3. **Fermer le couvercle du portable sans l’éteindre** – Cela met l’ordinateur en veille, pas en arrêt complet.  
4. **Cliquer plusieurs fois sur le bouton d’alimentation** – Un seul clic suffit; les autres peuvent être interprétés comme une demande d’arrêt d’urgence.

## À retenir  

- **Allumer** = appuyer doucement sur le bouton d’alimentation, attendre le logo.  
- **Éteindre** = passer par le menu (Démarrer ou ) puis choisir **Arrêter**.  
- **Redémarrer** = même chemin que l’arrêt, mais choisir **Redémarrer**.  
- **Ne jamais** débrancher avant que l’écran soit noir.  
- **Patience** : chaque étape dure quelques secondes, votre ordinateur a besoin de temps pour se préparer.

## Petit défi pour pratiquer  

1. Allumez votre ordinateur, laissez‑le arriver sur le bureau.  
2. Ouvrez le menu d’alimentation et choisissez **Éteindre**.  
3. Une fois l’écran noir, **rebranchez** le câble d’alimentation.  
4. Allumez à nouveau l’ordinateur.  

Répétez cet exercice deux fois de suite. Vous constaterez que chaque geste devient plus naturel, comme tourner la clé d’une porte que vous avez l’habitude d’ouvrir. Bon courage !
